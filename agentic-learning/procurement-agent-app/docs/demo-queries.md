# Demo Queries

Use these while practicing agent orchestration:

## Vendor Agent
- Recommend a vendor for 50 laptops under 100000 each
- Compare vendors for cost and rating
- Which vendor is best if delivery speed matters?

## Contract Agent
- Summarize the vendor contract
- What are the payment terms in the contract?
- What are the renewal and termination clauses?

## Risk Agent
- Assess risk for Vendor C
- Which vendor has the highest risk?
- Explain risk drivers for the supplier

## Orchestrator Practice
- Route vendor recommendation requests to vendor agent
- Route contract questions to contract agent
- Route supplier risk questions to risk agent
